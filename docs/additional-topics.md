# Additional Topics for 100xDevs 2.0

1. **Design a URL Shortener** — Hashing, collision handling, analytics
2. **Design a Chat Application** — WebSockets, message queues, presence
3. **Design a Rate Limiter** — Token bucket, sliding window, distributed
4. **Design a Notification System** — Push/pull, fan-out, delivery guarantees

5. **Docker Deep Dive** — Multi-stage builds, layer caching, security scanning
6. **Kubernetes Essentials** — Pods, services, deployments, HPA
7. **CI/CD Pipeline Design** — GitHub Actions, caching strategies, deployment patterns

11. **OWASP Top 10 Deep Dive** — XSS, CSRF, SQL injection prevention

13. **API Security** — Rate limiting, input validation, CORS, CSP

### Database & Caching
14. **Redis Patterns** — Caching, pub/sub, streams, distributed locks
15. **Database Indexing** — B-trees, composite indexes, query optimization
16. **Event Sourcing** — CQRS, projections, snapshotting

### Testing
17. **Testing Strategies** — Unit, integration, E2E, property-based testing
18. **Load Testing** — k6, Artillery, performance budgets

### AI/ML Integration
19. **Building with LLM APIs** — Prompt engineering, streaming, function calling
20. **RAG Systems** — Embeddings, vector databases, chunking strategies
